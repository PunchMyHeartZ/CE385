# สรุป Workshop 1 (CE385 · Week 2)

## ข้อ 1 — บัตรแนะนำตัวนักศึกษา (workshop1-1.js)

ข้อนี้ฝึกการประกาศตัวแปรด้วย const เพื่อเก็บข้อมูลนักศึกษา ได้แก่ ชื่อ รหัสนักศึกษา อายุ ภาควิชา และปีที่จบ ส่วนรายวิชาที่ลงทะเบียนใช้ array เก็บเพราะมีหลายค่า แล้วนำมาแสดงเป็นบัตรแนะนำตัวด้วย console.log โดยใช้ method join(", ") รวมสมาชิกของ array เป็นข้อความเดียวให้อ่านง่าย

## ข้อ 2 — ชนิดข้อมูลใน JavaScript (workshop1-2.js)

ข้อนี้ทดลองประกาศตัวแปรครบทุกชนิด ได้แก่ string number boolean undefined null และ array แล้วใช้ typeof ตรวจชนิดของแต่ละตัว สิ่งที่น่าสนใจคือ typeof null ได้ "object" ซึ่งไม่ถูกต้องตามความเป็นจริงเพราะเป็น bug เก่าแก่ของ JavaScript ที่เก็บไว้เพื่อความเข้ากันได้ นอกจากนี้ยังได้เรียนรู้ว่า Number("abc") จะได้ NaN ตรวจได้ด้วย Number.isNaN() และการเทียบค่าด้วย === จะเทียบทั้งค่าและชนิด ดังนั้น "20" === 20 เป็น false แต่ Number("20") === 20 เป็น true

## ข้อ 3 — เครื่องคิดเลขคะแนน (workshop1-3.js)

ข้อนี้คำนวณคะแนนรวมของนักศึกษารายวิชา CE385 โดยเก็บเกณฑ์คงที่ เช่น คะแนนเต็ม 60 น้ำหนัก 20 คะแนนเต็ม 100 และเป้าหมาย 80 ไว้ใน const ที่ตั้งชื่อสื่อความหมาย แทนการพิมพ์ตัวเลขดิบกลางสูตร คะแนน Workshop ถูกแปลงด้วยสูตร (คะแนนดิบ / 60) × 20 ได้ 16 คะแนน รวมทุกส่วนได้ 81.00 คะแนน คิดเป็น 81.00% และเกินเป้า 80 จึงเหลือ -1.00 การแสดงผลใช้ Template Literal พร้อม toFixed(2) แสดงทศนิยม 2 ตำแหน่ง โดยต้องระวังว่า toFixed() คืนค่าเป็นข้อความไม่ใช่ตัวเลข จึงใช้เฉพาะตอนแสดงผลเท่านั้น

## ข้อ 4 — ตัดเกรดจากคะแนน (workshop1-4.js)

ข้อนี้เขียนฟังก์ชัน toGrade(score) ตัดเกรด A ถึง F ด้วย if/else if จุดสำคัญคือต้องเรียงเงื่อนไขจากคะแนนมากไปน้อย เพราะโปรแกรมจะจบทันทีที่เจอเงื่อนไขแรกที่เป็นจริง จึงเช็คแค่ขอบล่าง เช่น score >= 80 ได้เลยโดยไม่ต้องเช็คขอบบนซ้ำ ก่อนตัดเกรดต้องตรวจข้อมูลนำเข้าก่อนว่าอยู่ระหว่าง 0-100 หรือไม่ ถ้าไม่ใช่ให้คืน null และไม่ตัดเกรด ส่วนการทดสอบใช้ for...of วนคะแนน 13 ค่ารวมกรณีขอบ เช่น 80 ต้องได้ A และ 79 ต้องได้ B+ เพื่อยืนยันว่าเงื่อนไขถูกต้อง

## ข้อ 5 — ระบบสั่งอาหาร (workshop1-5.js)

ข้อนี้ใช้ switch เขียนระบบคิดราคาเมนูอาหาร แบ่งเป็นสองฟังก์ชันคือ getMenuPrice(menu) หาราคาเมนู และ getSizeMultiplier(size) หาตัวคูณขนาด (ธรรมดา 1, พิเศษ 1.5, จัมโบ้ 2) จุดสำคัญคือมี 3 เมนูที่ราคา 50 เท่ากัน จึงใช้ fall-through รวม case เข้าด้วยกันแทนการเขียนซ้ำ 3 ครั้ง ทุก switch ต้องมี default โดยเมนูที่ไม่มีในรายการจะได้ 0 บาท การคิดราคาต่อรายการใช้สูตร ราคาเมนู × ตัวคูณขนาด × จำนวน แล้ววนคำนวณออร์เดอร์ทั้งหมดด้วย for...of รวมทั้งบิลได้ 695 บาท นอกจากนี้ยังใช้ trim() ตัดช่องว่างหน้าหลังข้อความก่อนเทียบ เพราะ switch เทียบค่าแบบ === เป๊ะ ๆ

## ข้อ 6 — ระบบตรวจสอบสิทธิ์ (workshop1-6.js)

ข้อนี้เป็นการรวมทุกหัวข้อ เขียนฟังก์ชัน login ที่ตรวจตามลำดับ คือ ชื่อผู้ใช้/รหัสผ่านก่อน ตามด้วยสถานะบัญชี ตามด้วยอายุ และสุดท้ายจึงแยกสิทธิ์ตาม role เหตุผลที่ต้องตรวจตัวตนก่อน role เพราะ role คือข้อมูลหลังจากพิสูจน์ตัวตนสำเร็จแล้ว ถ้าตรวจ role ก่อน คนแปลกหน้าแค่ส่ง role เป็น "อาจารย์" มากับมือก็ได้สิทธิ์ผู้ดูแลทั้งที่ตัวตนยังไม่ได้ยืนยัน และถ้าย้ายการตรวจอายุขึ้นมาเป็นข้อแรก ระบบจะเปิดเผยข้อมูลให้คนที่ยังไม่ได้พิสูจน์ตัวตนมากเกินจำเป็น ซึ่งเป็นช่องโหว่ด้าน information leak ในทางปฏิบัติฟังก์ชันต้อง return ข้อความผลลัพธ์ ไม่ใช่ console.log ข้างใน แล้วค่อย log ตอนเรียกใช้ พร้อมทดสอบ 6 กรณีครบทั้งสำเร็จและไม่สำเร็จ
